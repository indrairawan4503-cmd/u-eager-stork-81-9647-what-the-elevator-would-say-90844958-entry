Variant C: the elevator's existential dread — it only ever goes up and down, and it has started keeping a diary.

> Dear diary: up, down, up, down. A man whispered "I love you" to my doors, so I held them shut and pretended it was me.

`main.py` writes the line to `/output/entry.txt` (1–120 characters, deterministic, no network).
